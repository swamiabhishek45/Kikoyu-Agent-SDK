# Kikoyu Agent SDK

An Agent SDK for building AI agent workflows with type-safe tools, memory, execution loops, and streaming capabilities.

## Monorepo Layout

- `packages/core` — Main SDK package (`@kikoyu/core`)
- `examples/` — Standalone usage scripts

## Scripts

- `pnpm build` — Build all packages
- `pnpm test` — Run all tests
- `pnpm lint` — Run linting across packages
