# Class: AgentBuilder

Defined in: [agent-builder.ts:19](https://github.com/swamiabhishek45/Kikoyu-Agent-SDK/blob/b94d381587e8366b37c07b8fc4dec57c4a1ff640/packages/core/src/agent-builder.ts#L19)

Fluent builder for constructing validated [Agent](Agent.mdx) instances using method chaining.

## Example

```typescript
const agent = Agent.builder()
  .setName('Support Agent')
  .setInstructions('Help users resolve issues.')
  .setModel(new OpenAIProvider())
  .addTool(myTool)
  .build();
```
