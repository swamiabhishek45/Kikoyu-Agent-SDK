# Class: Agent

Defined in: [agent.ts:22](https://github.com/swamiabhishek45/Kikoyu-Agent-SDK/blob/fd5334209785cdbaf60bdba3de735d9bc8da851d/packages/core/src/agent.ts#L22)

Immutable configuration holder for an AI Agent.

All execution logic is driven by [Runner](Runner.mdx), while the Agent holds instructions,
attached tools, guardrails, and handoffs.

## Example

```typescript
const agent = new Agent({
  name: 'Assistant',
  instructions: 'You are a helpful AI assistant.',
  model: new OpenAIProvider(),
});
```
