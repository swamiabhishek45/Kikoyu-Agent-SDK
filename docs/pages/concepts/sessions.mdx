# Sessions & Persistent Memory

`Session` manages conversation turn history across multiple `Runner.run()` calls using a storage-agnostic `MemoryStore` interface.

## Available Memory Storage Adapters

Kikoyu provides four built-in memory storage adapters:

### 1. `Mem0Store` (Mem0 AI Long-Term Memory)
Integrates natively with [Mem0 (mem0.ai)](https://mem0.ai) for cloud-synced long-term agent memory across sessions.

```typescript
import { Agent, Mem0Store, OpenAIProvider, Runner, Session } from '@kikoyu/core';

// Mem0 Memory Adapter
const mem0Store = new Mem0Store({
  apiKey: process.env.MEM0_API_KEY,
  userId: 'user_123',
});

const session = new Session('session_101', mem0Store);

const agent = Agent.builder()
  .setName('Memory Agent')
  .setInstructions('Remember user preferences long term.')
  .setModel(new OpenAIProvider())
  .build();

const runner = new Runner();
await runner.run(agent, 'My favorite color is blue', { session });
```

### 2. `InMemoryStore` (Default Local Memory)
Keeps session history in Node.js memory (`Map`). Ideal for local testing and fast single-process apps.

```typescript
import { InMemoryStore, Session } from '@kikoyu/core';

const session = new Session('chat_session_101', new InMemoryStore());
```

### 3. `FileStore` (Persistent Local File Storage)
Saves conversation histories as JSON files on disk inside a specified directory (defaults to `.kikoyu-store/`). Persists history across server restarts without external databases.

```typescript
import { FileStore, Session } from '@kikoyu/core';

const fileStore = new FileStore({ directoryPath: './saved-sessions' });
const session = new Session('chat_session_101', fileStore);
```

### 4. `RedisStore` (Distributed Production Memory)
Delegates session storage to a Redis client (e.g. `ioredis`, `@upstash/redis`) for distributed server clusters and serverless deployments.

```typescript
import { RedisStore, Session } from '@kikoyu/core';
import Redis from 'ioredis';

const redis = new Redis(process.env.REDIS_URL!);
const session = new Session('chat_session_101', new RedisStore(redis));
```
